# 우리 학교 버전 만들기

순서대로 따라가면 됩니다. **1~2단계만 해도 우리 학교 이름으로 돌아가고**,
3~6단계는 할수록 우리 학교처럼 보입니다. 중간에 멈춰도 괜찮습니다.

| 단계 | 하는 일 | 고치는 파일 | 대략 걸리는 시간 |
|---|---|---|---|
| 0 | 준비 | — | 20분 |
| 1 | 내 저장소로 복사해 띄우기 | — | 10분 |
| 2 | **학교 이름·수능일·급식** | `src/data/school.js` · `index.html` | 10분 |
| 3 | 공간 이름과 소개 글 | `src/scenes/registry.js` | 20분 |
| 4 | 응원 문구에 우리 학교 색깔 | `src/data/phrases.js` | 30분 |
| 5 | 교복 색 | `src/engine/avatar.js` | 20분 |
| 6 | 학교 모양(건물 배치) | `src/scenes/front.js` · `rear.js` | 2~6시간 |
| 7 | 함께 접속하고 공개하기 | Firebase | 40분 |

각 단계마다 **AI에 붙여 넣을 요청문**을 두었습니다. Claude Code나 Codex를 저장소 폴더에서 열고
그대로 붙여 넣으시면 됩니다. 저장소 안의 [AGENTS.md](../AGENTS.md)를 AI가 자동으로 읽기 때문에,
"학교 도면을 넣지 마라" 같은 규칙은 따로 말씀하지 않으셔도 지켜집니다.

## 0단계 — 준비

**깔아야 하는 것**

- [Node.js](https://nodejs.org) 20 버전 이상 — 받아서 그냥 다음을 누르면 됩니다
- [Git](https://git-scm.com)
- GitHub 계정
- AI 코딩 도구 — [Claude Code](https://claude.com/claude-code) 또는 Codex (없어도 2~4단계는 손으로 됩니다)

**모아 두면 좋은 것** (6단계에서 씁니다. 저장소에는 넣지 않고 보기만 합니다.)

- 학교 **항공사진**(지도 앱의 위성 보기를 캡처)
- **배치도**나 학교 안내도
- 정문·본관 앞 **로드뷰 캡처**
- 교복 색을 확인할 수 있는 사진 (학교 누리집의 교복 안내 등)

> ⚠️ 이 자료들은 `_참고자료/` 폴더에 두세요. `.gitignore`에 들어 있어 저장소에 올라가지 않습니다.
> 보고 좌표와 색으로 옮긴 뒤에는 자료 자체를 커밋하지 마세요.

## 1단계 — 내 저장소로 복사해 띄우기

1. 이 저장소 위쪽 초록색 **[Use this template] → Create a new repository**
2. 이름은 `hanbit-cheer` 처럼 영문 소문자·숫자·하이픈으로 적습니다. 한글은 쓸 수 없습니다. **Public/Private은 나중에 바꿀 수 있습니다.**
3. 내 컴퓨터로 받아서 띄웁니다.

```bash
git clone https://github.com/<내-아이디>/<저장소-이름>.git
cd <저장소-이름>
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5191` — **○○고등학교**라고 적힌 교문이 나오면 성공입니다.
Firebase를 아직 안 붙였으니 "혼자 보는 중"으로 뜹니다. 정상입니다.

> 멈출 때는 터미널에서 `Ctrl + C`.

## 2단계 — 학교 이름·수능일·급식 ★ 여기만 해도 됩니다

`src/data/school.js` 한 파일입니다. 이 값들이 교문 간판·전광판·탭 제목·응원 문구에 한꺼번에 들어갑니다.

```js
export const SCHOOL = {
  name: '○○고등학교',           // 교문·본관 간판
  short: '○○',                  // 전광판, 응원 문구 ("○○이 응원해")
  appName: '○○ 수능 응원 공간',  // 브라우저 탭 제목
  appTagline: '잠깐 들어왔다 나가도 괜찮은 곳',
  audience: '○○고 학생·졸업생·선생님·학부모 누구나',
  neis: { office: '', school: '' },   // 급식
  examDate: '2026-11-19',             // D-day 기준
  examLabel: '2027학년도 수능',
  campus: { annex: '별관' },          // 본관 뒤 건물 이름
};
```

**`short`는 2~3글자**로 하세요. 간판과 말풍선 칸이 그 길이에 맞춰져 있습니다.
받침은 신경 쓰지 않으셔도 됩니다 — "한빛이 응원해 / 하나가 응원해"를 코드가 알아서 고릅니다.

### 급식 코드 찾기

1. [나이스 교육정보 개방 포털](https://open.neis.go.kr) → **학교기본정보(schoolInfo)**
2. 학교 이름으로 검색
3. `ATPT_OFCDC_SC_CODE` → `office` (서울 `B10`, 경기 `J10`, 부산 `C10` …)
   `SD_SCHUL_CODE` → `school` (숫자 7자리)

비워 두셔도 됩니다. 자습실의 '오늘 급식' 창만 "설정되지 않았어요"로 뜨고 나머지는 그대로 돌아갑니다.

### 하나 더 — 공유 미리보기

카카오톡·문자로 주소를 보낼 때 뜨는 제목은 `index.html`에 따로 있습니다. 두 줄만 고치세요.

```html
<meta property="og:title" content="수능 응원 공간" />
<meta property="og:description" content="잠깐 들어왔다 나가도 괜찮은 곳." />
```

### AI에 시키려면

```
src/data/school.js 를 우리 학교 값으로 바꿔 줘.

- 학교 이름: 한빛고등학교
- 짧은 이름: 한빛
- 수능일: 2026-11-19 (2027학년도 수능)
- 나이스: 시도교육청 코드 B10, 학교 코드 7010000
- 본관 뒤 건물 이름: 백양관

index.html 의 og:title, og:description 도 같이 맞춰 주고,
npm test 와 npm run build 를 돌려서 통과하는지 확인해 줘.
```

## 3단계 — 공간 이름과 소개 글

15개 공간의 이름·설명·색은 `src/scenes/registry.js`에 한 줄씩 들어 있습니다.

```js
{ id: 'annex', zone: 'rest', name: `${SCHOOL.campus.annex} 앞 낙엽 벤치`,
  scene: 'rear', spawn: 'annex', icon: 'leaf', color: '#d0682f',
  desc: '벤치에 앉아 떨어지는 단풍과 은행잎을 봐요. 낙엽을 잡으면 응원이 와요.' },
```

- `name` · `desc` — 자유롭게 고치세요. 우리 학교에서 부르는 이름으로요.
- `id` — 주소에 쓰입니다(`?space=annex`). 영문 소문자로, 바꾸면 `scene`·`spawn`도 함께 맞춰야 합니다.
- `scene` — 실제로 그리는 장면(`src/scenes/index.js` 목록). **공간을 지우려면 이 줄만 지우면 됩니다.**

> 우리 학교에 없는 공간(옥상·강당)은 줄을 지워도 되고, 이름만 바꿔 다른 장소로 써도 됩니다.
> 기원 공간(법당·성당·교회)은 지우셔도 되지만, **남기신다면 "학교의 실제 시설이 아닌 가상 공간" 표기를 지우지 마세요.**

```
src/scenes/registry.js 의 공간 이름과 설명을 우리 학교에 맞게 바꿔 줘.
- '별관 앞 낙엽 벤치' → '백양관 앞 은행나무 길'
- 옥상 공간은 우리 학교는 못 올라가니 목록에서 빼 줘
- 설명 문장은 지금처럼 '~해요' 말투로, 두 줄 넘지 않게
빼고 나서 npm test 통과하는지 확인해 줘.
```

## 4단계 — 응원 문구

`src/data/phrases.js`에 요일별·공간별 문구가 들어 있습니다. 전부 합쳐 250개가 넘습니다.

- `DAY_POOLS` — 요일마다 15개씩 (월요일 문구, 금요일 문구 …)
- `ROOM_POOLS` — 공간마다 (`soft` `spicy` `temple` `study` `exam` `roof` `forest` `annex` …)
- `EXAM_DAY` — 수능 당일
- `AFTER_EXAM` — 수능 끝난 뒤 (1·2학년도 함께 쓰는 쉼 문구)

학교 이름을 넣고 싶으면 글자를 박지 말고 이렇게 씁니다.

```js
`이번 주에도 ${josa(SCHOOL.short, '이', '가')} 너를 응원해.`,
```

> 문구는 **한 줄 60자 미만**으로 써 주세요. 말풍선 칸에 맞춰져 있고, 시험이 길이를 검사합니다.

```
src/data/phrases.js 의 응원 문구에 우리 학교 느낌을 더해 줘.

- 우리 학교는 산 중턱에 있어서 등굣길 계단이 길어. 그걸 소재로 한 문구를 몇 개 넣어 줘.
- 교화가 백목련이야.
- 기존 문구를 지우지 말고 추가만 해 줘.
- 학교 이름이 들어가면 josa() 를 써서 조사를 맞춰 줘.
- 한 줄 60자를 넘기지 말고, 다 쓴 뒤 npm test 로 확인해 줘.
```

## 5단계 — 교복 색

`src/engine/avatar.js` 맨 위 상수 한 줄입니다.

```js
const NAVY = 0x253560, NAVY_DARK = 0x1c284b, COBALT = 0x2f63e0,
      WHITE = 0xfbfbf7, SOCK = 0x1f2742, SHOE = 0x2f2621;
```

- `NAVY` 재킷 · `NAVY_DARK` 치마 바탕 · `COBALT` 리본 · `WHITE` 블라우스
- `0x` 뒤 여섯 자리는 색 코드입니다. 그림판이나 색 고르기 도구에서 `#253560` 형태로 뽑아 `0x253560`으로 적습니다.
- 머리 모양·색은 `HAIR_COLORS` · `HAIR_STYLES`에 있습니다.

```
src/engine/avatar.js 의 교복 색을 우리 학교에 맞춰 줘.
재킷은 진회색 #3a3d44, 넥타이는 자주색 #7b2d4a, 블라우스는 흰색 그대로.
바꾸고 나서 npm run dev 로 띄워서 캐릭터를 앞쪽에서 캡처해 보여 줘.
```

> 남녀공학이라면 바지 교복도 필요합니다. 지금은 치마 한 종류입니다 —
> AI에 "바지 교복 종류를 추가하고 별명 번호에 따라 번갈아 나오게 해 줘"라고 시키면 됩니다.

## 다 하고 나서 — 점검표

```bash
npm test          # 9개 통과
npm run build     # 빌드 성공
npm run dev       # 띄워서 직접 걸어 보기
```

- [ ] 교문 간판·전광판에 **우리 학교 이름**이 나오는가
- [ ] D-day 숫자가 맞는가 (`?time=2026-11-19T08:45` 로 수능날을 미리 볼 수 있습니다)
- [ ] 자습실 '오늘 급식'이 우리 학교 급식인가
- [ ] 기원 공간에 "학교의 실제 시설이 아닌 가상 공간" 표기가 남아 있는가
- [ ] **휴대폰으로 열어 봤는가** (가로로 돌려서. 교실에서 학생들은 휴대폰으로 봅니다)
- [ ] 저장소에 학교 도면·사진·명렬표가 섞여 들어가지 않았는가 (`git log --stat`)
