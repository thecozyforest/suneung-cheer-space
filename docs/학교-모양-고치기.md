# 학교 모양 고치기

건물은 사진이나 3D 파일이 아니라 **코드 속 숫자**로 그려져 있습니다.
"가로 24, 세로 10, 높이 6.4짜리 벽돌 상자를 여기에 둬라" 같은 식입니다.
그래서 우리 학교 모양으로 바꾸는 일은 **숫자를 바꾸는 일**입니다.

> **안 하셔도 됩니다.** 지금 모양은 흔한 한국 고등학교처럼 생겼습니다.
> 간판 글자만 우리 학교면 학생들은 알아봅니다. 시간이 있을 때 조금씩 하셔도 됩니다.

## 먼저 알아야 할 세 가지

### 1. 좌표

- 숫자 **1이 약 1미터**입니다. 캐릭터 키가 1.4, 담장이 1.1, 교실 문이 2.3입니다.
- **x**는 동서(오른쪽이 +), **z**는 남북(**카메라 쪽·정문 쪽이 +**), **y**는 높이입니다.
- 앞마당 장면에서 정문은 `z = 41` 근처, 본관은 `z = -16` 근처입니다. 즉 **북쪽으로 갈수록 z가 작아집니다.**

### 2. 땅은 평평하지 않습니다

`heightAt(x, z)` 함수가 그 자리의 땅 높이를 돌려줍니다.
앞마당은 `TOP = 1.6`만큼 높고, 계단과 경사로가 그 사이를 잇습니다.

```js
const TOP = 1.6;                                   // 앞마당 높이
const STAIRS = [-22, 0, 22];                       // 계단 세 곳의 x 위치
const RAMP = { x0: 38, x1: 42, zTop: -4, zBot: 10 }; // 동쪽 경사로
```

뒤뜰은 세 단입니다.

```js
const L1 = 0, L2 = 1.2, L3 = 2.6;  // 강당 앞 · 농구장 · 별관 앞
```

**건물을 옮기면 `heightAt`도 같이 봐야 합니다.** 안 그러면 캐릭터가 공중에 뜨거나 땅에 묻힙니다.

### 3. 벽은 따로 세웁니다

눈에 보이는 상자와 **못 지나가게 막는 벽**은 별개입니다.

```js
block(G, 24, 6.4, 10, 0, 2, L3, -52, { material: wallM }); // 보이는 건물
S.colliders.push(rect(2, -52, 24.4, 10.4));                // 막는 벽 (조금 크게)
```

건물을 옮기면 `colliders`의 좌표도 같이 옮겨야 합니다. 안 그러면 **허공에 보이지 않는 벽**이 남습니다.

## 쓸 수 있는 도우미 (`src/scenes/kit.js`)

| 함수 | 만드는 것 |
|---|---|
| `block(부모, 가로, 높이, 세로, 회전, x, y, z, 옵션)` | 상자 하나 (건물·벽·단) |
| `floor(S, 가로, 세로, x, z, 재질, y)` | 걸을 수 있는 바닥 |
| `solid(S, x, z, 가로, 세로)` | 못 지나가는 벽 |
| `sign(부모, '글자', {w,h,x,y,z,ry,bg,fg})` | 간판 (여러 줄은 배열로) |
| `spot(S, {id,label,pos,at,onUse})` | 누르면 걸어가서 무언가 하는 표시 |
| `bench(S, x, z, ry)` · `lieMat(S, x, z, {})` · `floorSeat(S, x, z, {})` | 앉는 자리 · 눕는 돗자리 · 방석 |
| `forest(부모, [{x,z,kind}])` | 나무 심기 (`round`·`pine`·`ginkgo`·`maple`·`autumn`·`shrub`) |
| `lamp(부모, x, z)` | 가로등 |
| `room(S, {w,d,h,...})` | 실내 방 틀 (남쪽 벽을 낮게 잘라 들여다보는 구조) |
| `door(S, {x,z,label,to,api})` | 다른 공간으로 가는 문 |

재질은 `brickTexture()`(벽돌) · `grassTexture()` · `sandTexture()`(흙 운동장) · `woodTexture()` · `tileTexture()`가 있습니다.

## 어떤 파일을 고치나

**`src/scenes/front.js`** — 정문·담장 · 계단식 앞마당 · 붉은 벽돌 L자 본관 · D-day 전광판 ·
흙 운동장 · 물결 차양 관람석 · 동쪽 경사로

**`src/scenes/rear.js`** — 본관 뒤 오르막 · 강당(목재 데크) · 농구장 · 별관 · 서쪽 숲길과 벤치

두 파일 모두 `// ── 본관 (L자) ──` 처럼 **구역마다 주석**으로 나뉘어 있습니다.
고치려는 구역을 주석으로 찾아 들어가면 됩니다.

**`src/scenes/hall.js`** — 복도 (벽·바닥·문 색)

## 실제로 하는 순서

### 1. 종이에 먼저 그립니다

항공사진을 띄워 놓고 **정문을 (0, 41) 기준**으로 삼아, 건물마다 네 가지를 적습니다.

```
본관   : 가로 78 × 세로 14, 4층(높이 14), 중심 (2, -16)
체육관 : 가로 30 × 세로 20, 높이 9,       중심 (-30, -40)
운동장 : 가로 80 × 세로 50,               중심 (0, 5)
```

항공사진에서 운동장 긴 쪽이 보통 100m쯤 됩니다. 그걸 기준으로 다른 건물 크기를 가늠하면 빠릅니다.
**정확할 필요 없습니다.** 걸어 다닐 때 "아 우리 학교네" 하면 충분합니다.

### 2. 한 번에 하나씩 고칩니다

본관 → 띄워서 확인 → 운동장 → 확인. 여러 개를 한꺼번에 바꾸면 어디서 틀어졌는지 못 찾습니다.

### 3. AI에 시킬 때

종이에 적은 숫자를 그대로 주는 것이 가장 잘 통합니다.

```
src/scenes/front.js 의 본관을 우리 학교 모양으로 바꿔 줘.

지금은 L자인데 우리 학교는 一자야.
- 본관: 가로 78, 세로 14, 4층(높이 14), 중심은 x=2, z=-16
- 현관은 가운데 (x=2) 에 있고, 그 앞에 폭 6짜리 계단 세 단
- 벽돌색은 지금보다 밝은 주황빛 (#b86b4a)

colliders 도 같이 맞춰 주고, heightAt 과 어긋나지 않는지 봐 줘.
고친 뒤 npm run dev 로 띄워서 정문 쪽에서 본관이 보이게 캡처해서 보여 줘.
```

> **캡처해서 보여 달라고 꼭 말하세요.** 숫자만 맞고 실제로는 이상하게 보이는 경우가 많습니다.

### 4. 확인합니다

```bash
npm run dev
```

- 교문에서 본관까지 **걸어가 보기** — 막히는 곳, 공중에 뜨는 곳이 없는지
- 계단과 경사로를 **올라가 보기**
- 휴대폰 가로 화면으로도 한 번

## 자주 겪는 일

| 증상 | 원인 |
|---|---|
| 캐릭터가 공중에 떠서 걷는다 | 건물을 옮겼는데 `heightAt`을 안 고쳤습니다 |
| 아무것도 없는데 막힌다 | `colliders`에 옛 건물 자리가 남아 있습니다 |
| 건물 안이 비쳐 보인다 | 상자를 세웠지만 `material`을 안 줬거나 `cast: false`입니다 |
| 간판 글자가 잘린다 | `sign`의 `tw`(글자 칸 너비)를 키우세요 |
| 밤에 창문에 불이 안 들어온다 | 창문 `name`을 `'djwin'` 같은 이름으로 찾아 켭니다. 새 건물이면 그 처리를 더해야 합니다 |

시설 보안과 저작권 문제가 생길 수 있고, 한 번 올리면 지워도 git 기록에 남습니다.
