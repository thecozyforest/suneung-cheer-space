# 함께 접속하고 공개하기

여기까지 안 하셔도 **혼자 보기로는 완전히 동작합니다.** 교실 TV에 띄우는 용도라면 1~2단계로 충분합니다.
친구들이 서로 보이게 하고 주소로 공유하려면 Firebase가 필요합니다. 40분쯤 걸립니다.

구글 계정만 있으면 되고, **무료 범위 안에서 씁니다.** 카드 등록도 필요 없습니다.

---

## 1. Firebase 프로젝트 만들기

1. [Firebase 콘솔](https://console.firebase.google.com) → **프로젝트 추가**
2. 이름은 `hanbit-cheer-2026` 처럼 영문으로 적습니다. 프로젝트 ID는 영문 소문자·숫자·하이픈으로 정해지고 공개 주소에 그대로 쓰입니다. Google 애널리틱스는 **끄셔도 됩니다**(학생 기기를 추적할 이유가 없습니다).

## 2. 실시간 데이터베이스 켜기

**빌드 → Realtime Database → 데이터베이스 만들기**

- 위치: **`asia-southeast1`(싱가포르)** 를 권합니다. 한국에서 가장 빠릅니다.
- 보안 규칙: **잠금 모드**로 시작하세요. 어차피 4단계에서 우리 규칙으로 덮어씁니다.

> Firestore가 아니라 **Realtime Database**입니다. 이름이 비슷하니 주의하세요.

## 3. 익명 로그인 켜기

**빌드 → Authentication → 시작하기 → 로그인 방법 → 익명 → 사용 설정**

학번도 이메일도 받지 않고, 브라우저마다 임시 번호를 하나씩 주는 방식입니다.
이게 있어야 "본인 자리만 지울 수 있다"는 규칙이 성립합니다.

## 4. 설정값 가져와 붙이기

**프로젝트 설정(톱니바퀴) → 내 앱 → 웹(`</>`)** 으로 앱을 추가하면 `firebaseConfig` 뭉치가 나옵니다.
`src/firebase-config.js`를 열어 맨 아래 주석 모양대로 채웁니다.

```js
export const firebaseConfig = {
  apiKey: '...',
  authDomain: 'hanbit-cheer-2026.firebaseapp.com',
  databaseURL: 'https://hanbit-cheer-2026-default-rtdb.asia-southeast1.firebasedatabase.app',
  projectId: 'hanbit-cheer-2026',
  storageBucket: 'hanbit-cheer-2026.firebasestorage.app',
  messagingSenderId: '...',
  appId: '...',
};
```

> **이 값들은 공개되어도 되는 값입니다.** 브라우저로 내려가는 코드에 어차피 들어갑니다.
> 진짜 보호는 다음 단계의 보안 규칙이 합니다. 다만 **서비스 계정 키**(`*-firebase-adminsdk-*.json`)는
> 완전히 다른 물건이니 **절대 저장소에 넣지 마세요.**

## 5. 보안 규칙 올리기 ★ 빠뜨리면 안 됩니다

저장소의 `database.rules.json`을 그대로 올립니다.

```bash
npm i -g firebase-tools
firebase login
firebase deploy --only database --project <내-프로젝트-id>
```

이 규칙이 하는 일:

- **읽기는 로그인한 사람만**, 방 이름이 형식에 맞을 때만
- **자기 칸만 쓰기** — 남의 별명·위치를 고칠 수 없습니다
- **빈자리만 앉기** — 이미 앉은 자리를 뺏거나 남을 일으켜 세울 수 없습니다
- **응원 수는 한 번에 +1만** — 숫자를 1000으로 조작할 수 없습니다
- 이름 8자, 위치 ±200 같은 **값의 범위 검사**

> 이 단계를 건너뛰면 데이터베이스가 **잠금 모드**라 아무도 못 들어오거나,
> 처음에 '테스트 모드'로 만드셨다면 **누구나 전체를 지울 수 있는 상태**가 됩니다. 꼭 올리세요.

## 6. 공개하기

```bash
npm run build
firebase deploy --only hosting --project <내-프로젝트-id>
```

`https://<내-프로젝트-id>.web.app` 주소가 나옵니다. 이게 학생들에게 줄 주소입니다.

- `.firebaserc`는 `.gitignore`에 들어 있어 저장소에 남지 않습니다. 매번 `--project`로 지정하거나
  `firebase use --add`로 한 번 등록해 두세요.
- 학교 도메인을 붙이고 싶으면 **Hosting → 맞춤 도메인**에서 됩니다.

## 7. 올린 뒤 꼭 확인

- [ ] **휴대폰으로** 열어서 걸어 보기 (가로 화면)
- [ ] 다른 기기 두 대로 같은 공간에 들어가 **서로 보이는지**
- [ ] 자리에 앉았다 일어나기, 응원 보내기
- [ ] 주소를 단톡방에 붙여 **미리보기 제목**이 맞게 뜨는지

## 무료 한도 (Spark 요금제)

| 항목 | 한도 |
|---|---|
| 실시간 DB 동시 접속 | **100명** |
| 실시간 DB 내려받기 | 하루 360MB |
| 호스팅 전송 | 하루 360MB |

**101번째 사람은 자동으로 '혼자 보기'로 들어갑니다.** 화면은 다 보이고 다른 사람만 안 보입니다.
오류 화면이 뜨거나 못 들어가는 일은 없습니다.

- **한 반·한 학년(30~300명)이 띄엄띄엄 들어오는 정도**면 무료로 충분합니다.
- **전교생에게 한꺼번에 공지**(조회 시간에 다 같이 접속)하면 100명을 넘깁니다.
  그때는 **Blaze(종량제)** 로 올리는 것을 검토하세요. 넘은 만큼만 과금되고,
  **예산 알림**을 걸어 두면 갑자기 많이 나오는 일을 막을 수 있습니다.
- 지금 몇 명이 들어와 있는지는 Firebase 콘솔 **Realtime Database → 사용량**에서 봅니다.

## 데이터는 무엇이 남나

- 접속 중인 사람의 **별명·위치·동작** — 나가면 사라집니다(`onDisconnect`).
- 오늘 눌린 **응원 수·켜진 초 수** 같은 숫자 — 날짜별로 쌓입니다. 누가 눌렀는지는 남지 않습니다.
- **글은 저장되지 않습니다.** 애초에 글 입력창이 없습니다.

학교에 안내해야 한다면 이렇게 쓰시면 됩니다 —
"로그인·학번 입력 없이 접속하며, 이름·연락처를 수집하지 않습니다. 접속 중 임시 별명과 위치만 쓰이고 종료 시 삭제됩니다."

## 안 될 때

| 증상 | 볼 곳 |
|---|---|
| 계속 "혼자 보는 중" | `firebase-config.js`의 `databaseURL`이 비었거나 오타. 주소에 `?solo`가 붙어 있지 않은지도 확인 |
| 들어가는데 서로 안 보임 | 익명 로그인이 꺼져 있습니다 (3단계) |
| 콘솔에 `PERMISSION_DENIED` | 보안 규칙을 안 올렸습니다 (5단계) |
| 배포는 됐는데 빈 화면 | `npm run build`를 안 하고 올렸습니다. `dist/`가 비어 있는지 보세요 |
